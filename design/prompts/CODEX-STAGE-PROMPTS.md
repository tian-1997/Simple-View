# Codex 分阶段提示词

## 阶段 0：仓库审查（只读）
请完整检查 WinIsland 仓库，不修改文件。梳理入口、Python / QML 架构、主题、窗口属性、桥接、Agent / 通知适配器、测试、打包。对照 UI 设计规范输出差距分析、材质可行性、品牌素材清单、拟修改文件和测试计划。明确哪些通知字段实际不可读取。完成后停止，等待批准。

## 阶段 1：设计系统与品牌资产
仅在批准后执行。建立设计 token、深浅主题和图标映射；按资产指南获取并本地化真实 Logo，维护 Manifest。不得改业务逻辑。补充资源预览和测试，完成后停止等待批准。

## 阶段 2：玻璃材质最小实验
仅在批准后执行。先用独立最小窗口验证 Windows 系统材质 / Qt 合成。分别验证窗口透明、背景模糊、tint、边缘高光、阴影、圆角、点击命中、拖动、置顶、DPI、多屏。记录真实效果截图与结论，不要先改完整 UI。完成后停止等待批准。

## 阶段 3：胶囊与主面板
仅在批准后执行。按设计规范实现顶部胶囊、Header、Agent 会话区、消息通知区和底部操作区。Agent 区在上，通知区在下。优先保证信息层级与可读性。不得使用概念图里的虚构数据。补充 UI / 功能测试与截图。完成后停止等待批准。

## 阶段 4：详情与交互
仅在批准后执行。实现详情、折叠、主题切换、未读状态等既有范围内交互。任何字段缺失时如实显示，不得编造。完成后停止等待批准。

## 阶段 5：兼容性与性能
仅在批准后执行。测试 Windows 11、100 / 125 / 150 / 200% DPI、多显示器、长文本、空列表、多个 Agent / 通知、材质降级、点击命中、托盘与窗口生命周期、性能。提交完整验收报告，等待最终批准。
