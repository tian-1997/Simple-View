# Codex 总提示词：WinIsland 玻璃质感 UI 改版

你正在维护 WinIsland，一个基于 Python + PySide6 + QML 的 Windows 桌面通知 / Agent 聚合应用。

## 首要目标
按 `docs/UI-DESIGN-SPEC-v1.0.1.md` 与 `preview/WinIsland-glass-concept.png` 实施视觉改版。目标是现代 OS 风格的真实玻璃质感：
- 深色主题：明显的深色半透明磨砂玻璃，背景光影可透过；
- 浅色主题：白色磨砂玻璃，透出背景颜色但保持高可读性；
- 顶部胶囊和展开面板使用统一玻璃材质语言；
- 蓝色强调色，独立 WinIsland 品牌识别；
- Agent 会话在上，消息通知在下。

## 不可违反的工程边界
1. 先完整检查仓库、README、AGENTS.md、依赖、入口、QML、Python bridge、数据适配器、状态机、测试和打包方式。
2. 不得只看局部文件就开始改造。
3. 保留现有数据适配器、通知采集、Agent 状态机、Python/QML Bridge、托盘、窗口显示 / 隐藏行为。
4. 不改变数据语义，不伪造通知正文、发送者、Agent 状态、项目名、最近动作或时间。
5. 不删除现有功能，不擅自扩展产品范围。
6. 不引入运行时网络图片 / 图标加载；品牌素材必须本地打包。
7. 不在未验证的情况下声称 Windows Acrylic / Mica / DWM 效果已实现。
8. 先验证最小可行材质实验，再决定实现路径。区分窗口透明、背景模糊、tint、边缘高光。
9. 如果系统材质方案不兼容，提供清晰回退方案，不得破坏窗口稳定性、点击命中、阴影和 DPI。
10. 严格测试先行：先写 / 更新验收测试，再实现。遵守仓库已有测试体系。

## 工作流程
### 阶段 0：只审查，不改代码
- 输出完整项目结构与关键模块关系。
- 标注现有窗口 / QML 结构、主题机制、透明窗口能力、系统材质能力。
- 盘点 Agent / 消息适配器实际支持的产品和可用字段。
- 列出需要下载的品牌 Logo，逐个核实官方来源、许可和文件格式。
- 列出拟修改文件、潜在风险、测试方案。
- 不修改任何文件，不下载或替换资产，不开始实现。
- 提交审查报告，等待用户确认。

### 阶段 1：设计系统与素材
用户批准后才执行：
- 建立 / 整理 Design Tokens、主题切换与图标映射。
- 下载真实品牌 Logo 至本地目录，记录来源和许可至 `assets/ASSET-MANIFEST.json`。
- 品牌素材与功能图标分离。
- 提供资源预览页或截图；无可信来源的素材使用中性占位。
- 完成后报告变更与验证，等待用户确认。

### 阶段 2：材质技术验证
用户批准后才执行：
- 创建最小独立验证分支 / 页面 / 实验窗口，不要先改完整主界面。
- 对比可行的 Windows 系统材质方案与 Qt Quick 合成方式。
- 验证真实背景模糊、窗口透明、tint、描边 / 高光是否同时可用。
- 测试点击穿透、窗口阴影、圆角、置顶、拖动、显示 / 隐藏、多屏与 DPI。
- 输出实测截图和技术结论，等待用户确认。

### 阶段 3：顶部胶囊与主面板
用户批准后才执行：
- 依照规范实现胶囊和主面板。
- 先实现布局、主题与材质，再实现微动效。
- 保留所有既有业务数据与交互语义。
- 提交截图、测试结果、文件变更清单，等待用户确认。

### 阶段 4：详情与交互细节
用户批准后才执行：
- 实现 Agent / 通知详情与交互细节。
- 仅展示当前数据源真实提供的信息。
- 区分正文可读、仅事件、无法读取。
- 完成后等待用户确认。

### 阶段 5：兼容性与性能验收
- Windows 11；100 / 125 / 150 / 200% DPI；多显示器。
- 长文本、空数据、单条与多条数据。
- 玻璃材质不可用时的回退。
- 空闲 CPU 目标 <1%（如无法达到，报告测量数据，不得伪报）。
- 检查窗口稳定性、点击命中、内存、启动和关闭行为。

## 每阶段报告格式
1. 本阶段目标与完成情况
2. 修改文件清单
3. 测试 / 验收命令与真实结果
4. 截图或录屏路径
5. 已知问题与风险
6. 是否需要用户决策

**阶段门禁：每阶段完成后必须停止并等待用户明确批准，禁止自动进入下一阶段。**
