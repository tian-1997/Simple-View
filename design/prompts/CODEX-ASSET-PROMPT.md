# Codex 提示词：下载 Agent / 聊天应用品牌 Logo

请先检查 WinIsland 仓库中实际存在的 Agent 适配器、消息应用适配器、配置项和运行时来源，不要根据产品设想猜测支持范围。

任务：
1. 列出当前真正支持的 Agent 与消息应用。
2. 对每个产品寻找官方 Logo：优先官方品牌资源中心、官网、官方 GitHub 组织 / 仓库。
3. 核实来源 URL、许可 / 再分发限制、是否官方素材、是否需要署名。
4. 只下载许可条件允许随应用分发的素材；许可不明确时不要下载，记录为待确认。
5. 优先 SVG；其次透明 PNG。保留原始品牌色、比例与轮廓。
6. 保存到 `assets/agents/` 或 `assets/messaging/`；WinIsland 自身 Logo 放 `assets/branding/`。
7. 将每个素材的来源、许可、下载日期、格式、官方属性写入 `assets/ASSET-MANIFEST.json`。
8. UI 功能图标与品牌 Logo 分开管理；功能图标统一使用轻量线性风格。
9. 不要从未知图标聚合站下载；不要使用网络 URL 作为运行时资源。
10. 未找到可信素材时使用中性占位，不得自行仿造 Logo。

交付：
- 支持产品清单；
- 素材文件清单；
- 每项来源和许可说明；
- 资源预览图；
- 未解决的许可问题。

本任务只做素材盘点与素材准备，不改 QML 页面，不改变业务逻辑。先报告计划，待用户批准后下载。
