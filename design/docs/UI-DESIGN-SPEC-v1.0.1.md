# WinIsland UI 设计规范 v1.0.1
## 方向与目标

**方向：Modern OS / Windows Fluent Evolution。** 借鉴现代桌面操作系统的轻量、秩序与材质表达，但不直接复制 Windows Fluent。整体要求：克制、清晰、轻量、精确，有独立品牌识别。

**本轮已确认的视觉方向：**
- 深色 / 浅色双主题。
- 深色：明显的深色半透明磨砂玻璃，能感知桌面壁纸的颜色与光影。
- 浅色：白色磨砂玻璃，透出背景色彩，但比深色更克制，优先保证文字对比度。
- 面板与顶部胶囊都使用玻璃材质，不要做成普通不透明圆角卡片。
- 蓝色作为系统强调色。
- 品牌采用独立品牌识别，不用纯通用符号替代 WinIsland 品牌。
- Agent 会话区在上，消息通知区在下，纵向堆叠。

## 设计参考

以 `preview/WinIsland-glass-concept.png` 为视觉方向参考。参考其：
- 背景与玻璃面板之间可见的透光关系；
- 面板边缘的细微高光、描边和柔和阴影；
- 深色面板的蓝黑玻璃层次；

- 顶部胶囊与展开面板使用统一材质语言。

## 玻璃材质规范

### 深色主题
- 主面板采用深蓝黑半透明底材，目标是明显感知背景透过，而不是仅仅“深色卡片”。
- 背景模糊应真实作用于面板背后的桌面内容；叠加深色 tint，避免背景细节干扰正文。
- 面板边缘使用低强度浅色描边和顶部 / 边缘高光，体现玻璃厚度。
- 阴影柔和、范围适中，避免霓虹发光或过强外发光。
- 内容区域可用极轻微的透明层级区分，但不要每一行都做成独立卡片。

### 浅色主题
- 主面板以白色半透明磨砂为主，透出背景的色彩和明暗变化。
- 模糊强度与不透明度应高于深色主题的“遮挡感”，确保黑色文字易读。
- 边缘使用浅灰 / 白色细描边，阴影比深色主题更轻。
- 不允许退化为完全不透明的纯白卡片；如果平台合成能力不足，才允许使用不透明回退，并需记录限制。

### 关键实现要求
- 玻璃效果必须来自真实窗口 / 桌面背景合成能力，不得只用渐变色假装模糊。
- 优先评估 Windows 11 Acrylic / Mica / DWM 系统材质能力与 Qt Quick / QML 的兼容方式；结合当前项目运行方式选择可维护方案。
- 若系统级材质与 Qt 窗口透明存在冲突，先做最小实验验证，不要直接大面积改架构。
- 明确区分：窗口透明、背景模糊、面板 tint、边缘高光，这四者不是同一个效果。
- 必须提供降级路径：不支持系统材质时回退到半透明 tint + 描边 + 阴影；再失败时回退到不透明主题色。
- 不要以牺牲窗口稳定性、点击命中、阴影裁切、DPI 适配为代价追求玻璃效果。

## 字体与字号
- 中文：Microsoft YaHei UI / 系统 UI。
- 英文：Segoe UI Variable / 系统 UI。
- 路径、数字、技术标识可使用 Cascadia Mono。
- 面板标题 16px；区块标题 14px；Agent 名称 / 通知标题 13px；正文 12px；辅助信息 11px。

## 顶部胶囊
- 初始宽度目标 240px；最小 220px，最大 360px；高度 40px；圆角 20px。
- 左侧品牌标识，中间 Agent 会话摘要，右侧通知数量 / 状态入口。
- 内容优先级：错误 > 等待确认 > 活跃会话 > 未读数量 > 空闲。
- 空间不足时隐藏次要信息，禁止文字重叠或挤压图标。

## 展开面板
- 宽度目标 424px；最大高度 560px；圆角 22px；内边距 16px；区块间距 16px。
- 纵向布局：顶部 Header → Agent 会话 → 消息通知 → 底部操作区。
- Agent 行建议高度 54px；通知行建议高度 56px。
- Agent 行显示真实可用的 Agent 名称、项目、状态、最近动作、持续时间。
- 通知行显示来源应用、会话 / 发送者、正文摘要、相对时间、未读标记。
- 长文本单行或两行截断；不允许挤压时间与状态信息。
- 详情视图仅展示真实可用字段；对“正文可读 / 仅事件 / 无法读取”做明确区分。

## 图标与品牌
- 品牌 Logo 与功能图标分离。
- Agent / 聊天应用使用真实品牌 Logo；功能操作使用统一线性图标。
- 图标尺寸以 16 / 18 / 20px 为主，统一笔画和视觉重量。
- Logo 保持原始比例、形状和品牌色；不统一染成蓝色，不强制圆形裁切。
- Logo 可放入中性底板容器，但不可篡改品牌图形。
- 未找到可信 Logo 时使用中性占位图标，不得伪造品牌标识。

## 动效
- 展开 220ms；收起 160ms；面板出现 200ms；Hover 100ms；状态色变化 180ms；主题切换 180ms；通知淡出 160ms。
- 不使用无限 shimmer、呼吸灯、扫描线等持续吸引注意力的动效。
- 动效必须可关闭或尊重系统减少动态效果设置（若项目已有相关能力）。

## 主题模式
- 跟随 Windows 系统 / 固定深色 / 固定浅色。
- 强调色固定为蓝色，后续可配置但本轮不扩展设置范围。

## 兼容性与质量要求
- Windows 11 优先。
- 验证 100% / 125% / 150% / 200% DPI。
- 验证多显示器、不同缩放比例与窗口移动。
- 验证长项目名、长通知正文、0 / 1 / 多个 Agent、0 / 1 / 多条通知。
- 玻璃失效时必须有可读、稳定的回退效果。
- 空闲 CPU 目标低于 1%（以不引入回归为前提）。
- 不得改变数据语义，不得伪造不可读取的消息正文。

## 阶段门禁
1. P0 设计系统 / 品牌 / 素材盘点。
2. P1 顶部胶囊与主面板布局 / 材质。
3. P2 详情视图与交互细节。
4. P3 DPI / 多屏 / 性能 / 稳定性验收。

每一阶段先提交改动与测试结果，等待用户确认后再进入下一阶段。
